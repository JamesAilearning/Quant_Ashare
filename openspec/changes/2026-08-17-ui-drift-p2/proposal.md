# Proposal: 修 UI 漂移 P2——预设诚实化与结果页口径标注

## Why

承 P0/P1 同一轮审计的最后一档：页面不会让人跑错东西，但会让人**读错
数**或**选错配置**。本 change 的两条结论都经独立复核——其中结果页那条，
复核推翻了审计的成因归因。

### D8 战役冻结件与可跑预设混在一个下拉框

`config/presets/` 下 36 份全部平铺成普通选项，其中 **30 份是战役预注册/
认证冻结件**。选中它们时页面显示该预设名，而实际发出去的是日频 pipeline
配置：本页产出 standalone 配置、不解析 `extends`（父配置的窗口/成本/ST
口径全丢），`rebalance_*` / `risk_constraint_scope` / `output_dir` 等键
本页没有控件、提交时被静默丢弃。**操作人读到的节奏不是将要跑的节奏**，
而节奏正是本项目最贵的变量（周频 = 晋升成立的前提）。

### D9 「Production = 全量生产」是谎，且它真能跑

`config/presets/production.yaml` 是 `instruments: all` + `SH000300TR` +
日频单模型，与当前生产（csi800 / N5 三成员 / 周频 iso_week / 20 bps）
毫无关系。它不触发 csi800 守卫，宇宙/基准错配只给一条 warning（不拦），
所以**想复现生产的操作人按名字选它，会拿到一个完全不可比的结果**。

### D10 结果页把两种口径并排摆着，一处不标

复核实测（run `20260805_094309…`）：

- 主指标 / 总收益 / 净值曲线 / 月度收益都读自 nav 的 `strategy_return`，
  其源头 qlib `report_normal["return"]` 把成本**加回**了已扣成本的收益
  （`account.py:283` 的 `(now_earning + now_cost) / …`）——即**绝对毛**。
  本仓库自己取净口径时必须手工再减一次（`backtest_runner.py` 的
  `- report_normal["cost"]`），这正是反证。
- 风险卡最大回撤 **−22.51%** 与正下方回撤图 **−26.46%** 不是同一个数，
  **9 个有完整产物的 run 全部不一致**。
- 信息比率是**扣费后超额**，就摆在**绝对毛**主指标正下方（审计漏了这条）。

**复核推翻了审计对回撤差异的归因**：审计称差在「扣费后超额 vs 绝对毛」，
但实测差异有**三个**维度——减不减基准、扣不扣成本、**算术累计**
（qlib `risk_analysis` 默认 `mode="sum"`）还是几何累计——而**成本是其中
最小的一项**：该 run 上成本只解释 21bp，两数却差 395bp。按审计的表述写
标注，操作人仍然无法理解两个数为何差 4 个百分点。

## What changes

### W1 预设分类（判据自维护）

`classify_preset_names` 按「顶层是否有 `mode` 键」分组。该键是 UI 专用
（两条 runtime 入口都把它当未知键硬拒，而 UI 保存路径必然写入），所以
判据**自维护**：新存的预设自动进白名单、新落地的冻结件自动进黑名单，
无需任何人手工登记。实测切出 6 可跑 / 30 冻结。冻结件改为只读列出，
附三条**真实原因**与命令行复跑指引。

连带修 `_detect_preset`：此前扫全部 36 份，冻结件一旦被判为「当前生效」
就会命名一个下拉框已不提供的选项，选择框静默回落 Default 而内部状态说的
是另一个。

### W2 诚实化文案

「Production」改述为**全市场基线**（instruments=all，日频单模型），并
指明生产权威在 `config/serving/csi800_n5_production.yaml`；页面加一句
「本页产出的是日频研究配置」——三项与生产同值（宇宙/基准/topk）最容易
让人误以为这是生产配置的可编辑副本，而唯一不同的那项本页看不见也改不了。
`ensemble_window` 默认保持 1（dataclass 默认，改 3 会与 canonical 分叉），
改加 help 说明正典用 3 及其扫描证据。

### W3 结果页口径标注（按实证，不按审计表述）

主指标标为「绝对**毛**：未减基准、未扣成本」；IR 标为「扣费后超额」；
净值曲线与月度收益各自声明绝对毛并指出与 IR 不可直接相减；回撤图与风险
卡**互相**声明不是同一个数，并把**三处差异逐一写出**（基准 / 成本 / 累计
方式），明说「本就不相等」以免被当成 bug。收益卡 help 补上本项目最贵的
教训：毛净可以**反号**（csi800 战役毛 +3.68% 而净均为负）。

措辞沿用页面已有的正确范本（walk-forward 汇总那句「扣费后超额口径」）。

## 边界（本 change 不做）

- 不改任何数值、不改产物 schema、不新算指标——只标注既有字段的口径。
- 不改 `production.yaml` 的**内容**（可能有人依赖），只改它在 UI 上的
  自我描述；文件名保持（治理钉要求 smoke/default/production 存在）。
- 不改 `slippage_bps` / `ensemble_window` 的默认值（前者是治理钉死的
  base 敏感带 in-code 默认，后者是 dataclass 默认）。

# 工作台身份卡只报形态不报年龄：「模型多旧」要跳页才知道

## Why

今日工作台的身份卡说得清现任是谁（ensemble 三成员、宇宙、基准），但不说
它**多旧**、下一次成员该在什么窗口里训。这两个数生产运维页④早就在算
（`retrain_window`），操作人每次都要跳页去看——UI 评估已批序列的 P3 缺口。

## What Changes

- 身份卡 ensemble 分支追加三行：`fit 至` / `模型年龄` / `下一成员 fit_end
  窗（推导）`，数据**照抄**生产运维页④的 `retrain_window`，措辞层零判定。
- 窗口行在**可见文案**里自报「推导」身份：仓库没有机器可读的重训到期锚，
  窗口是从 serving 间距 pin 推导的——驾驶舱的披露契约跟着窗口走到每一处
  展示（codex #467 P1 补披露）。
- `known=False` 时如实说推导不了并带原因，不留空、不给默认值。

## 本 change **不新造**任何推导

生产运维页与工作台共用同一个 `retrain_window`（#461 首版另写一份、三个
决策全错的教训在档）；接线由源码钉守住。不新增写侧、不发明排期锚。

## Non-goals

- 不把「窗口已过」翻成任何催训文案之外的动作建议——点火排期归运维手册。
- 不动生产运维页④本身。
